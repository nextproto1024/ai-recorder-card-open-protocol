# QS668 AI录音卡 BLE 开放协议

本文档整理自 `website/app.js` 中已经实现的 Web Bluetooth 测试平台协议。

## BLE UUID

| 用途 | UUID | 方向 |
| --- | --- | --- |
| 主服务 | `0000ae20-0000-1000-8000-00805f9b34fb` | 发现服务 |
| 写入特征 | `0000ae21-0000-1000-8000-00805f9b34fb` | 主机写入设备 |
| 通知特征 | `0000ae22-0000-1000-8000-00805f9b34fb` | 设备通知主机 |
| 按键/机身事件通知 | `0000ae23-0000-1000-8000-00805f9b34fb` | 设备通知主机 |

## 协议帧格式

```text
偏移  长度  字段       说明
0     1     HEADER     固定 0x5A
1     1     SEQ        序号，0xFF 后回绕
2     2     CRC        CRC-16/XMODEM，小端
4     2     LEN        负载长度，小端
6     LEN   PAYLOAD    TYPE CMD PARAMS...
```

负载格式：

```text
TYPE CMD PARAMS...
```

CRC 计算范围：

```text
LEN_LO LEN_HI TYPE CMD PARAMS...
```

CRC 算法：CRC-16/XMODEM，多项式 `0x1021`，初始值 `0x0000`。

标准校验向量：

```text
crc16Xmodem("123456789") = 0x31C3
```

## 命令分组

| TYPE | 分组 |
| --- | --- |
| `0` | 设备控制与状态 |
| `1` | 实时音频 |
| `2` | 文件列表、导入、删除 |
| `3` | 录音控制与录音状态 |

## 常用命令

### TYPE 0：设备控制

| 请求 | 含义 | 说明 |
| --- | --- | --- |
| `0-0` | 同步时间 | 参数：年低位、年高位、月、日、时、分、秒 |
| `0-1` | 获取容量 | 响应 `0-2`，剩余 KB 和总 KB，小端 u32 |
| `0-3` | 获取电量 | 响应 `0-4`，百分比；`110` 表示充电中 |
| `0-10` | 获取固件版本 | 响应 `0-11`，文本 |
| `0-12` | 获取授权码 | 响应 `0-13`，ASCII/HEX |

### TYPE 1：实时音频

| 请求 | 含义 |
| --- | --- |
| `1-0` | 开始实时音频 |
| `1-2` | 结束实时音频 |
| `1-3 01` | 暂停实时音频 |
| `1-3 00` | 继续实时音频 |

实时数据通过通知帧接收。测试平台会把数据保存为 OPUS 系原始码流，并可分片提交后端 ASR。

### TYPE 2：文件

| 请求 | 含义 |
| --- | --- |
| `2-0` | 读取文件列表 |
| `2-2` | 从设备导入/下载文件 |
| `2-7` | 终止导入 |
| `2-8` | 删除单个文件 |
| `2-9` | 删除全部文件 |
| `2-12` | 分段导入 |

文件列表中的整数使用大端：

```text
COUNT_BE32
ENTRY...

ENTRY:
duration_or_time_BE32
size_BE32
filename_fixed_20_bytes
```

`2-2` 导入请求参数：

```text
offset_LE32 + filename_fixed_24_bytes
```

### TYPE 3：录音

| 请求 | 含义 |
| --- | --- |
| `3-1` | 开始录音 |
| `3-3` | 保存录音 |
| `3-5` | 暂停录音 |
| `3-7` | 继续录音 |
| `3-19` | 获取录音状态 |
| `3-21` | 获取录音时长和当前大小 |
| `3-23` | 获取当前文件名 |
| `3-25` | 获取增益 |
| `3-27` | 设置增益 |

`AE23` 特征还可以上报机身事件，例如开始、保存、暂停、继续。
