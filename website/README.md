# QS668 Web Bluetooth Tester

This directory contains the open-source code copied from the public QS668 AI recorder card tester:

<https://nextproto.top/qs668/>

The page uses Web Bluetooth, so it must run in Chrome or Edge over HTTPS or localhost.

```bash
python3 -m http.server 8080
```

Open:

```text
http://localhost:8080
```
