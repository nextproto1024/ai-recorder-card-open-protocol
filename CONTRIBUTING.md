# Contributing

Issues and pull requests are welcome.

Please include the following information when reporting protocol or hardware integration issues:

- Device model and firmware version
- Platform: Web Bluetooth, Android, iOS, desktop, or embedded host
- Browser/app version when relevant
- Raw TX/RX frame log when available
- Expected behavior and actual behavior

For protocol changes, update both:

- `docs/protocol.md`
- `docs/protocol.zh-CN.md`
